# Web UI preview scope

This branch carries the browser interface and its client-side modules. The
static preview can show the sample reader and navigation. Episode creation,
daily generation, saved profiles, and current audio require server APIs that
are not included here. A 404 or unavailable state from those routes does not
mean an episode was created.

Screenshots of request states use fictional data and mocked API responses.
They do not show a live generation service, paid provider call, or finished
recording.
